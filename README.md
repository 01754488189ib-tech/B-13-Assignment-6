1:- Project Name:- SwiftCart

2:- Description:- A React-based shopping cart project built as a course
         assignment  to practice dynamic data handling.

3:- Technologies Used:-
    React, 
    Tailwind-CSS, 
    DaisyUI, 
    React-Icons, 
    React-Toastify, 
    Figma, 
    GitHub, 
    Netlify.

4:- Features:-
    Product Cart: Easy item selection and adding to cart.
    Live Counter: Real-time item count updates on the cart icon.
    Toast Alerts: Interactive notifications for every user action.
